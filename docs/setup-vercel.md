# Vercel

Založte GitHub repozitář, pushněte kód, ve Vercelu vytvořte účet a importujte repozitář. Vyberte Hobby pouze pokud akce splňuje aktuální podmínky Vercelu pro osobní/nekomerční využití. Do Environment Variables vložte `NEXT_PUBLIC_SUPABASE_URL` a `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`; obě hodnoty jsou určené pro prohlížeč. Nasazení preview otestujte, pak označte produkční deployment.

Do Supabase Site URL a Redirect URLs i Google OAuth doplňte produkční `.vercel.app` URL. Vercel logy a Usage zkontrolujte před akcí. Vlastní doména je volitelná; pokud ji škola má, přidejte subdoménu podle pokynů Vercelu, jinak je `.vercel.app` plně funkční.

# Plán pro den akce

Po uzavření registrace exportujte seznamy účasti po přednáškách, kompletní rozpis studentů, seznam hostů a přiřazení místností. Uložte CSV a tisknutelné verze do zabezpečeného školního úložiště a mějte vytištěnou kopii pro koordinátory. Při výpadku webu se účast vede podle těchto uzavřených seznamů; online změny se nedělají bez pozdějšího zápisu administrátorem.
